### Step 2: 拡張機能を Chrome に読み込ませる

ここで「拡張機能ID」を取得します（これがGCPの設定に必要です）。

1. Chrome のアドレスバーに `chrome://extensions` と入力。
2. 右上の **「デベロッパーモード」** をONにする。
3. **「パッケージ化されていない拡張機能を読み込む」** をクリックし、作成したフォルダを選択。
4. 一覧に追加された拡張機能の **「ID: (32桁の英字)」** をコピーしてメモ帳に控える。

---

### Step 3: Google Cloud Console での設定 (超重要)

ここが最大の難関です。

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセス（個人のGoogleアカウントでOK）。
2. プロジェクトを作成（名前は適当でOK）。
3. **「API とサービス」** > **「ライブラリ」** へ移動。
4. `Google Calendar API` を検索して **「有効にする」**。
5. **「API とサービス」** > **「OAuth 同意画面」** へ移動。
* User Type: **外部 (External)** を選択（※個人の無料アカウントの場合）。
* アプリ名などを適当に入力。
* **テストユーザー** の欄に、**「動作確認に使う（あなたの会社用の）メールアドレス」** を必ず追加してください。これがないとエラーになります。


6. **「API とサービス」** > **「認証情報」** へ移動。
7. **「認証情報を作成」** > **「OAuth クライアント ID」** を選択。
* アプリケーションの種類: **Chrome 拡張機能**
* 名前: 適当に
* **アイテム ID:** Step 2 でコピーした「32桁の英字」を貼り付け。


8. 作成ボタンを押すと **クライアント ID** が発行されます。これをコピーします。

---

### Step 4: `manifest.json` の更新とリロード

1. エディタに戻り、`manifest.json` の `"YOUR_CLIENT_ID_GOES_HERE"` の部分を、Step 3 で取得した **クライアント ID** に書き換えて保存します。
2. Chrome の拡張機能管理画面 (`chrome://extensions`) に戻り、リロードボタン（回転矢印）を押します。

---

### Step 5: 動作確認

1. 拡張機能のアイコンをクリックしてポップアップを開きます。
2. 検索ボックスに、**「あなたの会社用のメールアドレス（またはカレンダー閲覧権限がある同僚のアドレス）」** を入力して検索ボタンを押します。
3. 初回のみ Google の認証画面が開きます。会社のアカウントを選択してログインしてください。
* ※「このアプリは Google で確認されていません」と出たら、「詳細」→「（安全ではないページ）に移動」を押してください。


4. カレンダーが表示されれば成功です！
